# Real Parallelism in Ruby with Ractors

Ractors, or Ruby Actors have been in development since before 2020, and support is just now starting to be rolled out to frameworks and libraries. Ractors allow true parallelism in a single Ruby process, which is a feature the language has been lacking since its release. In this talk, you'll learn about what Ractors are, how they're used, and some real world applications of them.

## Usage

```
> ./bin/install
> ./bin/server
```
